This repository contains supplementary material for a manuscript 
*"Sequence determinants of on-target hybridization efficiency 
in targeted capture sequencing revealed by interpretable machine learning"*
by  Aelita-Luiza Makarova; Alexander V. Vikhorev; Maria M. Gridina; 
    Pavel A. Salnikov; Elina R. Allayarova; Iulia G. Samoilova.

Supplementary material includes datasets with 
probe feature values,
target regions feature values, 
and coverage depth obtained from targeted sequencing experiments.

Repository contains three folders with datasets, figures,
and Python notebooks (.ipynb) that may be executed to reproduce
the study results. Methodology and results are described in the manuscript.
